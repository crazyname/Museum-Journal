# 草木观察录 / Museum Journal · Botanical Field Notes

植物博物学笔记本风格的单文件中文电子书。采用泛黄旧纸质感、手写体排版，以植物学基础知识连接实地科级鉴定与物种条目。


## 关于本书

《草木观察录》是《博物志》系列的植物分册，以华南地区（广东、广西、福建、海南）的野生植物和常见栽培植物为优先范围。全书将植物形态图谱、分类检索与科属物种图鉴结合起来，既适合系统了解植物，也便于按观察到的特征查阅。

本书采用**清晰易懂、科学严谨、自然生动的百科科普文风**。简单的形态可以用一句话讲清楚；复杂的结构、生长方式和辨认特征，则通过适当的比喻、实例和解释展开。文字的详略取决于知识本身，力求让读者读得明白，也能获得准确、具体的博物学知识。

## 版本 2 · 植物鉴定工作流

唯一网页入口为根目录 `index.html`。CSS、JavaScript、植物资料和交互式形态检索表全部封装在此文件内；使用浏览器打开即可阅读，无需框架、构建工具或服务器。

**全书 44 页（逻辑书页）**，结构如下：

1. 卷首封面、**书内目录**、前言；不再提供左侧侧栏。
2. **植物形态学教程**（10 章）：植物谱系与繁殖方式，根系与地下器官，茎／节／芽／生活型，叶形与叶缘，叶序与叶脉，花的解剖，花序，果实与种子，科级形态检索原则，以及现场观察记录。
3. **形态检索**：依据花果、孢子囊群、球果、叶形、叶脉、根茎及综合特征分支；支持返回上一步、重来和证据不足退出。
4. **科级索引**：13 个科各有独立的科页，介绍典型形态、区分方法与易混淆性状。
5. **植物志**：每个科页后直接排列该科已收录的物种。第一版沿用的 13 个示例种均保留，条目给出生境、叶枝、花果、辨认线索与插画留白。
6. 空白观察卡和版权页。

## 与普通知识检索的区别

**检索结果只是候选科，不是保证正确的植物鉴定。** 本册检索表仅能针对当前收录的 13 个科进行教学型缩小范围，不能排除书外的其他科，也不能以一项根系形态或叶形直接认定植物科属。

理想流程是：记录观察事实 → 学习形态术语 → 在检索页选择能够可靠确认的性状 → 翻到候选科的页码 → 核对多个科级特征 → 向后翻到本册对应物种 → 继续比较。

缺乏花、果、球果或孢子结构等重要证据时，允许以“证据不足”结束检索。不要为猜测植物名称而采集受保护植物、擅自挖根或触碰有毒部位。

## 阅读辅助

- **目录**：全书目录属于书内的正式页面；顶部仅保留“目录”返回按钮，不另设左侧树形导航。
- **字号**：`A−`、`A+` 分别缩小和放大，设定保存在浏览器本地。
- **纸色**：循环切换「旧纸 / 浅纸 / 白纸」。
- **搜索**：书页标题、学名、科名和部分正文关键词；键盘 `/` 快捷打开。
- **收藏**：通过本机浏览器 localStorage 保存书页收藏。
- **翻页**：底部前后页按钮、键盘 `←` 和 `→`；页面底部有动态页码。
- **打印**：整册内容排版为 A4 打印页，浏览器打印对话框也可以选择“保存为 PDF”。
- **响应式**：桌面和手机都采用单列书页阅读，不出现左侧目录。

## 分类依据与研究参考

- [Kew Plants of the World Online](https://powo.science.kew.org/)：当前植物学名、同物异名与分类群信息，特别是部分种的不同分类处理。
- [Flora of China](http://www.efloras.org/flora_page.aspx?flora_id=2)：中国植物科、属及形态学描述，后续扩充地区检索表时可参考。

**注意**：本版正文为重新编写的简要教学文本，不是转载上述数据库。若未来扩充到区域植物志，须分地区、分生境核验全部科与检索路径；严谨的科级鉴定通常需要多个器官的组合证据。
