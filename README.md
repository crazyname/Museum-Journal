# 博物志 · 第一编《草木》

**Museum Journal / Volume I — Flora of South China**

《博物志》是一套以自然观察和户外识别为核心的数字博物学图鉴。每一编是一本独立的电子书，对应一个可直接打开的 HTML 文件。第一编《草木》优先收录广东、广西、福建、海南的野生植物和常见栽培植物，今后可继续编写动物、真菌等独立分册。

## 关于本书

《草木》将植物形态图谱、野外检索表与科属种图鉴组合在一起。读者可以先了解叶形、叶序、花、果实和根茎的可见特征，再按照观察到的特征查找候选植物科，沿着**科 → 属 → 种**的顺序进入详细条目。全书同时提供按名称检索与按页码翻阅的阅读方式。

本书采用**准确、清晰、自然、生动，详略得当的百科科普文风**。简单概念用直接的语言说明，例如“扇形叶像一把展开的扇子”；复杂形态、易混淆特征或有趣的生物学现象，可根据需要使用更详细的比喻、解释和实例。文字的长短由内容决定，既保留必要的科学细节，也保持自然流畅的阅读感。正文避免空泛的教学提示、写作过程说明和不必要的否定性解释。

本书服务于**户外观察与植物识别**。植物细胞、组织切片、复杂的生理机制等大学植物学基础课程内容，不作为独立系统章节。植物学教材仍用于形态术语、器官知识与分类方法的科学核对。

## 版本 v3 · B6 野外识别版

仓库根目录的 [`index.html`](./index.html) 是第一编完整电子书，**CSS、JavaScript、文本数据均内嵌于这一个文件**，无须构建步骤或后端服务器。

目前内容：

- **卷首**：封面、书内目录、使用说明。
- **第一部分 · 植物形态图谱**：35 个独立术语书页，包括根系、地下茎、枝条、叶形、叶缘、叶序、复叶、花和花序、果实、孢子囊群等；原则上每页只说明一个形态主题。
- **第二部分 · 野外检索**：针对当前收录的 13 个示例科，按照可观察的枝、叶、花、果及繁殖结构逐步缩小候选范围；设独立科级索引。该交互检索属于**区域图鉴原型**，尚未覆盖全部华南植物。
- **第三部分 · 植物图鉴**：13 个科、13 个属与 13 个代表物种。每个科有独立介绍，每个属有独立过渡页，每个物种有形态、生境及识别特征。
- **卷末**：参考资料、图版状态和来源说明。

默认字号下目前为 **85 张 B6 书页**。页数随内容与字号排版动态变化；每一张纸始终保持相同的 B6 尺寸。新增植物时优先补齐科内属、种的正式检索资料，不将现有示例检索当作完整的植物志检索表。

## 纸张与阅读器

- **纸张**：统一 ISO B6，125 × 176 mm，整册所有页面采用同一纸张比例；内容过多时自动续到下一张 B6 页，不拉长纸张。
- **阅读**：桌面显示双页书册，手机显示单页；目录是书中的正式书页，没有左侧目录栏。
- **控制**：翻页、书内目录跳转、全文检索、A−/A+ 字号调节、旧纸／浅纸／白纸切换。
- **打印**：使用 CSS `@page { size: 125mm 176mm; margin: 0 }` 输出独立 B6 页，可在浏览器打印设置中另选缩放或拼版。
- **技术**：原生 HTML/CSS/JavaScript。纸张纹理由原创 CSS 和内嵌 SVG 噪声构成。

> 字号调大时，个别内容可能自动拆分为下一张同尺寸纸页；书内跳转页码会同步更新。

## 插画计划

形态页、科页、属页、物种页均保留手绘图版位置。后续插入原创或获授权的植物形态线描及水彩图，优先保证结构准确、比例一致。物种图版建议包括整体形态和必要的局部细节。当前没有打包第三方植物照片或插图。

## 科学资料与编纂原则

本项目以华南地区的现场识别为应用范围，科、属、种按现代植物分类学组织。正式扩充时以权威植物志中的形态描述和科、属、种检索表为主要参考，并对接受学名、异名和分布进行交叉核验。

主要参考：

1. [《中国植物志》](https://www.iplant.cn/frps)：中国植物的形态记述及分类资料。
2. [Flora of China](http://www.efloras.org/flora_page.aspx?flora_id=2)：植物科、属、种检索和系统描述。
3. [Plants of the World Online（Kew）](https://powo.science.kew.org/)：接受学名、异名、分类和分布核验。
4. 《植物学》高校教材及植物形态术语图解辞典：术语和可见器官的基础依据。

**编辑状态**：v3 是真实功能可用的图鉴原型；图版尚未加入，13 科的交互检索仅覆盖已收录的示例类群，不构成整个华南植物区系的完整鉴定工具。每个属目前只列出一例物种，是分期收录的结果。
