# 博物志 · 第一编《草木》

**Museum Journal / Volume I — Flora of South China**

《博物志》是一套以自然观察和户外识别为核心的数字博物学图鉴。每一编是一本独立的电子书，对应一个可直接打开的 HTML 文件。第一编《草木》优先收录广东、广西、福建、海南的野生植物和常见栽培植物，今后可继续编写动物、真菌等独立分册。

## 关于本书

《草木》将植物形态图谱、野外检索表与科属种图鉴组合在一起。读者可以先了解叶形、叶序、花、果实、根茎和其他肉眼可见的特征，再根据观察结果查找候选类群，并进入相应的科、属或种条目。

本书采用**准确、清晰、自然、生动，详略得当的百科科普文风**。简单概念用直接的语言说明，例如“扇形叶像一把展开的扇子”；复杂形态、易混淆特征或有趣的生物学现象，可根据需要使用更详细的比喻、解释和实例。文字的长短由内容决定，既保留必要的科学细节，也保持自然流畅的阅读感。正文避免空泛的教学提示、写作过程说明和不必要的否定性解释。

本书服务于**户外观察与植物识别**。植物细胞、组织切片、复杂的生理机制等大学植物学基础课程内容，不作为独立系统章节。植物学教材用于形态术语、器官知识与分类方法的科学核对。

## 版本 v4 · B6 野外识别电子书

仓库根目录的 [`index.html`](./index.html) 是第一编完整电子书，**CSS、JavaScript、文本数据和阅读器均内嵌于这一个 HTML 文件**，无须构建步骤或后端服务器。

目前内容：

- **植物形态图谱**：35 个独立术语书页，包括根系、地下茎、枝条、叶形、叶缘、叶序、复叶、花和花序、果实、孢子囊群等；每页聚焦一个形态主题。
- **野外检索**：针对当前收录的 13 个示例科，依据可观察的枝、叶、花、果及繁殖结构逐步缩小候选范围；检索结果可跳转到科页。该交互检索属于区域图鉴原型，尚未覆盖全部华南植物。
- **华南植物图鉴**：按科、属、种组织，当前收录 13 个科、13 个属和 13 个代表物种；科、属与种均有独立书页。
- **目录与索引**：目录完全展开，采用三级层级，条目显示实际页码并可直接跳转；另有科级索引、名称搜索与分类链接。
- **卷末资料**：参考资料与图版说明。

页数会随内容和字号变化；每张纸始终保持相同的 B6 尺寸。新增植物时优先补齐科内多个属、多个种及相应检索资料，不将现有示例检索当作完整的植物志检索表。

## 纸张与阅读器

- **纸张**：统一 ISO B6，125 × 176 mm；每一页尺寸相同，内容过多时自动延续到下一张 B6 纸页。
- **阅读布局**：桌面双页、手机单页。页眉只显示当前部分名称与页码，不设置页尾。
- **翻页**：点击左侧区域上一页、右侧区域下一页；手机支持左右滑动，桌面支持键盘左右方向键。
- **阅读工具栏**：点击页面中央显示或隐藏工具栏，提供目录、进度、搜索、字号、纸色和打印。目录条目选中后自动关闭并跳转。
- **目录**：书内正式目录完全展开，一级为章节，二级为分类索引，三级为具体形态、科属种条目；同时可从阅读工具栏打开目录面板。
- **阅读设置**：A−/A+ 调整字号，旧纸／浅纸／白纸切换底色，搜索中文名、学名、科名和形态术语。
- **打印**：使用 CSS `@page { size: 125mm 176mm; margin: 0 }` 输出独立 B6 页，可在浏览器打印设置中选择缩放或拼版。
- **技术**：原生 HTML/CSS/JavaScript，纸张纹理由原创 CSS 和内嵌 SVG 噪声构成。

## 插画版式与生成提示词

插画不限定为单一比例，支持横图、竖图、正方形及其他适合内容的构图。版面根据图片自身比例安排：

- 横向图版采用较低高度，可居中排在正文上方；
- 竖图或较小的方图缩至版心约三分之一宽度，与说明文字并排；左页图片靠左，右页图片靠右；
- 图片保持原始比例，不拉伸，不裁切关键器官；图版高度从严控制，正文优先；
- 图注紧邻图片，文字与图片之间保留适当留白；仅在确有必要时才让图版独占一页。

目前尚未插入最终手绘插画。每个图版位置以**针对该页具体主题编写的图像生成提示词**作为占位内容，说明植物或器官主题、关键形态结构、科学准确性、手绘技法、构图方向、背景和禁止项。后续生成或上传插画时，可按提示词替换对应占位，不使用泛化的“植物手绘图版”作为统一占位文字。

## 科学资料与编纂原则

本项目以华南地区的现场识别为应用范围，科、属、种按现代植物分类学组织。正式扩充时以权威植物志中的形态描述和科、属、种检索表为主要参考，并对接受学名、异名和分布进行交叉核验。

主要参考：

1. [《中国植物志》](https://www.iplant.cn/frps)：中国植物的形态记述及分类资料。
2. [Flora of China](http://www.efloras.org/flora_page.aspx?flora_id=2)：植物科、属、种检索和系统描述。
3. [Plants of the World Online（Kew）](https://powo.science.kew.org/)：接受学名、异名、分类和分布核验。
4. 《植物学》高校教材及植物形态术语图解辞典：术语和可见器官的基础依据。

**编辑状态**：当前版本是区域图鉴原型；图版尚未加入，13 科的交互检索仅覆盖已收录的示例类群，不构成整个华南植物区系的完整鉴定工具。每个属目前只列出一例物种，是分期收录的结果。
